# 🎓 EduGenie – AI Powered Learning Assistant

EduGenie is an AI-powered learning assistant that helps college students learn topics easily using Google Gemini.

## Features

- Ask a question
- Get an explanation for any topic
- Generate quizzes
- Summarize long content
- Get personalized learning recommendations

## Exploring EduGenie

### a. Asking Questions
Students can ask questions and get AI-generated answers in simple language.

### b. Explanation of Any Topic
EduGenie explains difficult topics in an easy-to-understand way with examples.

### c. Summarizing Long Paragraphs
EduGenie summarizes long content and provides the important points in simple language.

### d. Generating Quizzes
EduGenie generates multiple-choice questions with four options for each question.

### e. Learning Recommendations
EduGenie provides a step-by-step learning path from beginner to advanced level.

## Technologies Used

- Google Gemini API
